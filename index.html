PREGUNTAS FRECUENTES

¿Tienes alguna duda?

¿Cuánto tarda en hacerse una web?

Depende del proyecto, pero una web para un negocio local puede estar lista en pocos días una vez tengamos toda la información y las fotografías.

¿La web funciona en móvil?

Sí. Todas nuestras webs se diseñan para funcionar correctamente en móviles, tablets y ordenadores.

¿Puedo poner WhatsApp?

Sí. Podemos añadir botones para que tus clientes puedan contactar contigo directamente desde la web.

¿Puedo pedir cambios después?

Sí. También ofrecemos mantenimiento para actualizar información, fotografías, horarios, menús y otros elementos de la página.
